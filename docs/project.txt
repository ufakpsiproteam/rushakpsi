Brother Experience:
All brothers will have an account made prior to recruitment
Main page has a welcome and there are pages/screens for the following:
Events (shows date and time of events)
Events can be clicked to “Start Evaluation" once the event ends and Rushees leave 
There is a toggle on the admin side for each event to change a boolean of Accept Evals = False to True which will show a button on the event card so brothers can start the evaluation process. 
When the boolean is False they can see event details but cant enter or evaluate since that will be locked
When an event is clicked to start evaluation, all Rushees who attended are shown and the brother is asked to select all that they spoke/engaged with
The next screen shows just those that they engaged with and allows them to select any on the screen fill out an evaluation form for them
The brother can evaluate a minimum of 5 of those they engaged with but can do all if they wish
They click continue when they are done.
**evaluations on a Rushee can be updated at any time by brothers 
A page showing all the rushee’s
Brothers can click any to see details like their major/year
Brothers can write any personal notes for themselves
Brothers can star any Rushees they have their eye on
If they have evaluated a Rushee this is where they can update that
